# komapick（公開ページ用）

KomaPick（iPhone アプリ）のサポートとプライバシーポリシー。
GitHub Pages で `https://hobcraft.github.io/komapick/` に公開する。

- サポート: `https://hobcraft.github.io/komapick/support/`
- プライバシーポリシー: `https://hobcraft.github.io/komapick/privacy/`
- English: `https://hobcraft.github.io/komapick/en/`

**このリポジトリは公開される。アプリのソースや申請メモを入れないこと。**

## 公開の手順（未実施）

1. `privacy_policy.md` と `en/privacy_policy.md` の `[公開日]` を埋める
2. Mac の Terminal で `gh repo create hobcraft/komapick --public --source . --push`
3. GitHub の Settings → Pages で Source を `main` / `/ (root)` にする
4. 2 つの URL をブラウザで開いて表示を確かめる（404 だと審査で落ちる）
